# 👨‍💻 Eduardo Patrick — Dev Portfolio

Um portfólio web moderno e minimalista.

---

## ✨ Características

- 🎨 **Design Moderno** — Interface limpa e elegante com paleta de cores sofisticada
- 📱 **Responsivo** — Funciona perfeitamente em desktop, tablet e mobile
- ⚡ **Otimizado** — Carregamento rápido e performance excepcional
- 🌙 **Dark Mode** — Interface escura pensada para conforto visual
- 🎯 **UX Focada** — Experiência de usuário intuitiva e acessível

---

## 🛠️ Tecnologias Utilizadas

- **HTML5** — Semântica e estrutura
- **CSS3** — Animações, variáveis CSS e design responsivo
- **JavaScript** — Interatividade e funcionalidades dinâmicas
- **Fontes** — Cinzel, Noto Serif JP, Manrope (Google Fonts)

---

## 🎯 Seções Principais

### 1. **Hero Section**
Apresentação visual com informações principais e call-to-actions destacados.

### 2. **Projetos**
Exibição dos principais projetos desenvolvidos com descrição detalhada, tecnologias e resultados.

### 3. **Skills**
Competências técnicas organizadas por categorias.

### 4. **Educação**
Formação acadêmica e certificações.

### 5. **Sobre**
Informações pessoais e profissionais.

### 6. **Contato**
Links para redes sociais e opção de cópia de email com um clique.

---

## 🎨 Paleta de Cores

| Cor | Hex | Uso |
|-----|-----|-----|
| Background | `#0d0d0f` | Cor de fundo principal |
| Gold | `#c9a84c` | Destaque e botões |
| Texto | `#e8e6e1` | Texto principal |
| Muted | `#888` | Texto secundário |
| Accent | `#4fa3e0` | Links e acentos |
