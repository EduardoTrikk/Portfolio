Projeto 01

Sistema de Registro e Gestão de Softwares

TCC · Projeto de Conclusão de Curso

O Problema

Instituições e desenvolvedores independentes enfrentam dificuldade em documentar, registrar e gerenciar os softwares criados internamente. A falta de controle gera retrabalho, perda de rastreabilidade e exposição legal.

A Solução

Plataforma web completa para registro formal de softwares, com cadastro de versões, autores, artefatos e histórico de alterações — gerando documentação estruturada e auditável, com autenticação e controle de acesso por perfil.

Meu papel

Desenvolvimento fullstack: modelagem do banco de dados, criação da API REST, implementação do frontend e entrega de documentação técnica completa com diagramas UML e artefatos de engenharia.

Tecnologias
React Node.js Supabase PostgreSQL REST API JWT Auth
📋 Artefatos produzidos: Diagrama de casos de uso, mapa de empatia, protótipo de telas, documentação de requisitos e registro formal junto à instituição.
Projeto 02

Sistema de Automação via WhatsApp

Full Stack · Automação & Integração

O Problema

Empresas perdem horas diárias com atendimento repetitivo e manual via WhatsApp: agendamentos, confirmações, respostas a dúvidas frequentes e notificações que poderiam ser automatizadas sem perder a personalização.

A Solução

Bot inteligente integrado ao WhatsApp capaz de responder perguntas frequentes, processar fluxos de atendimento configuráveis e acionar integrações externas — tudo via painel de controle web, sem necessidade de código pelo cliente.

Meu papel

Implementação do backend de automação, integração com a API do WhatsApp, criação dos fluxos de conversação e desenvolvimento do painel administrativo para configuração das respostas automatizadas.

Tecnologias
Node.js WhatsApp API React Webhooks SQL REST API
⚡ Resultado: Redução significativa no tempo de atendimento manual, com fluxos configuráveis que permitem ao cliente gerir o bot sem suporte técnico.
Projeto 03

Aplicação Web com Autenticação e CRUD Completo

Full Stack · Projeto Acadêmico

O Problema

Necessidade de colocar em prática o ciclo completo de desenvolvimento de software — da concepção ao deploy — aplicando conceitos de segurança, UX, boas práticas de código e arquitetura limpa em um sistema real e funcional.

A Solução

Sistema web com autenticação segura, gerenciamento de usuários, painel com operações CRUD e design responsivo — desenvolvido seguindo princípios de Clean Code, componentização e separação de responsabilidades.

Meu papel

Projeto individual do frontend ao backend: arquitetura da aplicação, modelagem de banco, criação dos endpoints, integração front-back e aplicação de conceitos de segurança como hash de senhas e validação de entradas.

Tecnologias
React Node.js Supabase HTML/CSS JavaScript SQL
🔐 Segurança aplicada: Autenticação com hash, sanitização de inputs, controle de sessão e rotas protegidas por perfil de acesso.

04 — Sobre

Quem sou eu

Sou estudante de Engenharia de Software com foco em desenvolvimento Full Stack, apaixonado por criar soluções que realmente funcionam — do banco de dados à interface do usuário.

Ao longo da graduação, tive contato com todo o ciclo de vida do desenvolvimento: desde o levantamento de requisitos e artefatos de engenharia, passando pela modelagem de banco de dados e construção de APIs, até a entrega de interfaces responsivas centradas no usuário.

Acredito que bom código é código legível, manutenível e seguro. Por isso, aplico princípios de Clean Code, refatoração contínua e testes em tudo que construo.

Estou em busca de uma oportunidade para contribuir em um time que valorize qualidade técnica, colaboração e crescimento contínuo.
