Projeto 01

Brotar+ · Aplicativo para Comerciantes Hortifrutigranjeiros

TCC · Projeto de Conclusão de Curso

O Problema

Comerciantes de um centro de distribuição de alimentos no estado do Pará enfrentam dificuldades na divulgação de seus produtos, o que limita o alcance de clientes e impacta diretamente nas vendas. A baixa presença digital e a dependência do fluxo local reduzem a competitividade desses profissionais.

A Solução

Desenvolvimento do Brotar+, um protótipo de aplicativo mobile voltado à exposição de produtos e apoio às vendas. A solução permite que vendedores criem vitrines digitais, organizem seus produtos, atualizem preços e se conectem diretamente com clientes, ampliando sua visibilidade no ambiente digital.

Meu papel

Pesquisa com usuários reais (18 participantes), aplicação de Design Thinking, construção de mapa de empatia, definição de requisitos (histórias de usuário), prototipação de interfaces no Figma e desenvolvimento do protótipo funcional da aplicação.

Tecnologias
React Native Supabase Figma Node.js
📊 Resultados: Protótipo validado com usuários reais, considerado intuitivo e útil, com alta intenção de uso e potencial para ampliar vendas e alcance digital dos comerciantes.
Projeto 02

Copiloto de WhatsApp para Pequenos Negócios

Full Stack · SaaS · Automação com Voz · Projeto Independente

O Problema

Pequenos negócios que utilizam o WhatsApp como principal canal de vendas enfrentam sobrecarga operacional: precisam responder mensagens manualmente, organizar pedidos, gerenciar agendamentos e lembrar tarefas, tudo ao mesmo tempo. Isso reduz a produtividade e causa perda de oportunidades.

A Solução

Desenvolvimento de um copiloto inteligente para WhatsApp que automatiza o atendimento com foco em produtividade. O sistema lê mensagens em voz alta, permite respostas por comando de voz, cria lembretes automaticamente e organiza agendamentos e pedidos, reduzindo a necessidade de interação manual constante.

Meu papel

Idealização do produto, planejamento, organização e desenvolvimento. Arquitetura do sistema, modelagem do banco de dados, construção da API, integração com WhatsApp e implementação dos módulos de voz (speech-to-text e text-to-speech), além do planejamento de escalabilidade da plataforma.

Tecnologias
Node.js React Next.js PostgreSQL WebSocket WhatsApp API Speech-to-Text Text-to-Speech
⚡ Diferencial: Sistema orientado a voz que reduz interação manual, permitindo que o usuário opere o atendimento sem precisar tocar no celular constantemente.
Projeto 03

Climatic Adventure: Jogo Educativo sobre Mudanças Climáticas

Game Dev · Projeto Acadêmico · Hackathon NASA

O Problema

A conscientização sobre mudanças climáticas ainda enfrenta desafios no ambiente educacional, especialmente na forma de engajar crianças e adolescentes. Métodos tradicionais nem sempre estimulam reflexão crítica ou interesse contínuo sobre o tema.

A Solução

Desenvolvimento do jogo digital Climatic Adventure, uma experiência interativa baseada em decisões que impactam o mundo virtual. O jogador enfrenta situações do cotidiano relacionadas ao meio ambiente, aprendendo sobre o ODS 13 de forma lúdica, com feedback imediato e narrativa dinâmica.

Meu papel

Desenvolvimento do jogo utilizando a engine Godot, definição das mecânicas de gameplay, implementação da lógica de decisões e construção da experiência do usuário. Participação na coleta e análise de dados para validação do impacto educacional do projeto.

Tecnologias
Godot Engine GDScript Game Design UX Design Itch.io Assets
🌍 Impacto: 89,5% dos participantes relataram aprendizado sobre mudanças climáticas e 84,2% reconheceram o potencial do jogo para conscientização ambiental.
Projeto 04

Sistema de Cadastro com Persistência em Banco de Dados

Backend · POO · Projeto Acadêmico

O Problema

Aplicações simples frequentemente não possuem persistência de dados estruturada, dificultando o armazenamento, recuperação e manutenção das informações de forma consistente e segura.

A Solução

Desenvolvimento de um sistema de cadastro com operações CRUD integradas a banco de dados relacional, permitindo inserção, edição, consulta e exclusão de registros por meio de uma interface gráfica conectada ao backend.

Meu papel

Implementação utilizando conceitos de Programação Orientada a Objetos, modelagem das entidades, integração com banco SQL Server, criação das operações CRUD e estruturação da comunicação entre interface e banco de dados.

Tecnologias
Java POO SQL Server TSQL NetBeans
📊 Conceitos aplicados: Persistência de dados, modelagem relacional, encapsulamento, separação de responsabilidades e operações CRUD completas.
Projeto 05

Jogo Tetris desenvolvido em Python

Game Dev · Lógica · Projeto Independente

O Problema

Implementar um jogo clássico exige lidar com regras dinâmicas, controle de estados, colisões e renderização em tempo real, sendo um desafio relevante para consolidar lógica de programação e estruturas de dados.

A Solução

Desenvolvimento completo do jogo Tetris utilizando Python, com sistema de movimentação de peças, detecção de colisão, rotação de blocos, pontuação e controle de velocidade progressiva, simulando a experiência clássica do jogo.

Meu papel

Implementação da lógica do jogo, controle de estados, algoritmos de colisão e renderização da interface. Estruturação do código para manter organização e legibilidade, aplicando boas práticas de programação.

Tecnologias
Python Pygame Game Logic Algorithms
🎮 Destaque: Implementação completa das mecânicas clássicas do Tetris, incluindo rotação de peças, detecção de linhas completas e progressão de dificuldade.

04 — Sobre

Quem sou eu

Sou estudante de Engenharia de Software com foco em desenvolvimento Full Stack, construindo sistemas que vão além do código, eles são focados em resolver problemas reais e melhorar a rotina de quem usa.

Tenho experiência prática no desenvolvimento de aplicações completas, atuando desde a modelagem de dados e arquitetura backend até a criação de interfaces funcionais e objetivas. Já desenvolvi projetos envolvendo automação de processos, sistemas orientados a eventos e interação por voz.

Tenho interesse em segurança de aplicações, buscando reduzir falhas e aplicar boas práticas desde a construção do sistema. Também foco em soluções que aumentam produtividade, como automações e ferramentas que reduzem tarefas manuais no dia a dia.

Acredito que um bom sistema precisa ser simples de usar, seguro, eficiente e sustentável a longo prazo. Por isso, aplico boas práticas como organização modular, clareza de código, validação de dados e atenção à experiência do usuário desde o início.

Busco uma oportunidade para atuar no desenvolvimento de produtos reais, contribuindo com soluções práticas e evoluindo constantemente como desenvolvedor.
